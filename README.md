# RK ADMIN Android project

Open this folder in Android Studio and wait for Gradle sync. Then choose Build > Build Bundle(s) / APK(s) > Build APK(s).

Demo sign-in:
- Username: admin
- Password: admin123

Included:
- Login screen
- Admin dashboard and overview
- Add/remove users (stored in memory only)
- Settings screen
- Logout

Important: This is a working offline starter app project, not a prebuilt APK. User records reset when the app process is closed. There is no server, cloud sync, or production-grade authentication.
